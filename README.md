# El Silbato Digital ⚽📰

Periódico digital deportivo desarrollado como proyecto para clase utilizando HTML5 y Bootstrap 5.

## 🚀 Tecnologías utilizadas
- HTML5
- Bootstrap 5 (CDN)
- Git y GitHub

## 📁 Estructura del proyecto
- `index.html`: Página principal con la estructura de rejilla y tarjetas de Bootstrap.
- `images/`: Carpeta que contiene todas las imágenes locales de las noticias.
